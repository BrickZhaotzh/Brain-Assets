# 科创"好课"的教研系统：从专业设计到产品交付的工作框架

## 概览

本文档系统阐述了一套完整的科创课程教研工作框架，从战略规划到产品交付的全流程设计方法论。基于"技术重塑流程"的理念，采用UbD（Understanding by Design）框架，构建以"大概念"统领、以"表现性任务"驱动的科创课程体系。

## 核心理念

### 设计共识

我们将基于"技术重塑流程"的共识，运用**UbD框架**来系统构建以"大概念"统领、以"表现性任务"驱动的科创课程，并始终以"学生中心、真实问题、素养导向"的原则指导具体设计。

### 为什么选择UbD框架

1. **以"可持续理解目标"统整跨学科知识**
   - 科创教育的核心是培养学生解决真实世界复杂问题的能力
   - 必然涉及科学、技术、工程、人文等多领域的知识、思维与价值观的融合
   - UbD的"可持续理解目标"是能够超越单一学科知识点、融合多领域核心观念的**大概念**

2. **以"表现性任务"作为学习与评估的枢纽**
   - 科创素养必须在"做"中体现
   - 设计精良的表现性任务能自然驱动学生对各领域知识的综合应用
   - 使学习成果清晰可见、可评估

### "一节好课"的本质

**是系统节点，而非孤立事件**

一节好课，是学习生态系统中的**关键节点**。其价值在于实现两种深度作用：

1. **深度联结**：将学生经验、学科概念与真实问题整合贯通
2. **持续生成**：激发认知冲突与好奇，使本节课的结束成为下一阶段更自主探索的开始

### 三项核心原则

1. **学生中心**：设计服务于学生的认知发展与主动建构
2. **真实问题**：学习由对真实、复杂、有意义的问题探究所驱动
3. **素养导向**：目标指向可迁移的核心素养与持久性理解

## 完整的五阶段工作流

### 阶段一：宏观规划、产品定义与战略锚定

**目的**：为"大科创"课程产品确立清晰的战略方向、产品哲学与实施边界。

#### 核心任务

1. **战略环境与需求分析**
   - 政策与趋势解码
   - 市场与用户洞察
   - 新课标解构与素养融合建模

2. **产品顶层设计与定位**
   - 产品愿景与使命
   - 产品形态与结构决策
   - 一体化与复用战略

3. **内容蓝图与资源规划**
   - 核心主题领域圈定
   - 地域特色与前沿融合
   - 《资源复用白皮书》起草

#### 关键产出

- 《战略环境与需求分析报告》
- 《"大科创"课程产品规格说明书（V1.0）》
- 《资源复用与接口标准白皮书（草案）》

### 阶段二：学期课程宏观框架构建

**目的**：将战略定位转化为可执行、可评估的学期课程骨架。

#### 核心设计动作

1. **确定产品形态实现重心**
   - 明确设计侧重点
   - 规划实现路径

2. **规划学期主题序列与单元形态布局**
   - 确定2-6个单元的主题、顺序、课时
   - 设计认知节奏与项目周期

3. **设计素养与工具的连贯性"暗线"**
   - 确立2-3个本学期将持续贯穿培养的思维习惯
   - 统一使用的工具/平台

#### 关键产出

- 《产品形态实现重心说明书》
- 《学期主题序列与形态布局表》
- 《学期素养与工具连贯性指南》

### 阶段三：单元与课时的分级逆向设计

#### 子阶段3.1：单元顶层设计

**目的**：制定《单元规格说明书》，锁定单元核心价值。

**核心内容**：

1. **确立单元的"预期结果"（UbD Stage 1）**
   - 可迁移的"大概念"与理解
   - 核心问题
   - 素养成长目标

2. **确定单元的"评估证据"（UbD Stage 2）**
   - 核心表现性任务
   - 其他评估证据

**关键产出**：《单元规格说明书（初稿）》

#### 子阶段3.2：课时级逆向设计与开发

**目的**：规划通往终极表现性任务的学习路径，分解落实到每一节课。

**核心任务**：

1. **规划学习路径（UbD Stage 3 初构）**
   - 分解问题链
   - 规划课时序列

2. **进行课时级UbD设计**
   - 本课焦点问题
   - 本课学习目标
   - 本课评估
   - 本课学习体验

3. **完成资源与脚手架设计**

**关键产出**：《单元教学包（完整版）》

### 阶段四：一体化教学验证、复用效益评估与迭代优化

**目的**：在真实教学场景中验证设计决策的有效性，定量评估资源复用效益。

#### 核心任务

1. **设计有侧重的试点验证方案**
2. **实施试点与深度数据收集**
3. **多维度数据分析与效益评估**
4. **数据驱动的精准迭代**

#### 关键产出

- 《一体化教学验证与复用效益评估报告》
- 《修订版课程资源包V1.1》
- 《产品与设计框架迭代建议书》

### 阶段五：产品封装、交付与生态化持续支持

**目的**：将经过实证检验的课程资源，转化为标准化、可规模化交付的"教育产品"。

#### 核心任务

1. **产品标准化封装与平台化部署**
2. **交付物体系构建与启动支持**
3. **构建持续进化与价值共创生态**

#### 关键产出

- 《"大科创"课程产品正式版V1.0》
- 《产品实施与支持白皮书》
- 《资源复用与二次开发指南》
- 《教师启动培训套件》
- 《产品迭代路线图V1.0》

## 多元视角下的"好课"框架

| **视角维度** | **核心关切** | **"好课"的关键体现** |
| :--- | :--- | :--- |
| 校长/管理视角 | 示范性、安全性、品牌效应 | 流程规范可展示，体现办学理念，无安全隐患 |
| 教研/专家视角 | 科学性、逻辑性、创新性 | 目标精准符合课标，结构严谨有探究性，方法前沿 |
| 教师/实操视角 | 可行性、生成性、成就感 | 准备充分易实施，学生投入，能灵活调整 |
| 学生/体验视角 | 趣味性、参与感、获得感 | 好玩有挑战，能做到，与我的世界相关 |
| 家长/价值视角 | 实用性、可见性、长期影响 | 孩子能展示所学，能力有提升，兴趣被激发 |
| 教育技术专家视角 | 赋能性、必要性、无痕融合 | 技术是探究的必需工具而非装饰，降低门槛 |
| 跨学科融合视角 | 连接性、整体性、意义建构 | 自然连接多学科，促进整体认知构建 |
| 教育公平视角 | 包容性、支持性、机会均等 | 每个学生都能获得有意义的参与和成就感 |
| 长期主义视角 | 思维播种、习惯养成、未来指向 | 播下超越具体知识的思维与价值观种子 |
| 企业/产品视角 | 标准化、规模化、效果可验证 | 课程易于复制推广，效果可测量展示 |

## 视频素材策略

### 核心结论

不需要、也不应该每节课都配同样规格的高质量视频素材。

### 策略建议："二八原则"下的素材分级投入

#### S级（必须精做）

- **适用场景**：
  1. 整个课程/每个单元的"启动器"（第一节课或单元导入）
  2. 核心概念的"破壁器"（最抽象、最难理解的核心原理）
  3. 项目实践的"导航仪"（关键操作步骤、安全须知、复杂项目启动）

- **投入策略**：加大投入，制作高品质视频（如高质量动画、实拍微电影）
- **替代方案**：不可替代，或只能用成本相近的互动动画替代

#### A级（值得做好）

- **适用场景**：
  1. 现象/案例的"展示窗"（展示不易观察的现象、前沿科技应用）
  2. 拓展知识的"传送门"（与核心内容强相关的趣味延伸）

- **投入策略**：采用高性价比方式，如高质量录屏+配音、精修图文动画
- **替代方案**：可用高质量的交互式图文（H5）、信息图替代

#### B级（可巧做或不做）

- **适用场景**：
  1. 常规知识讲解（可通过阅读、教师讲解清晰传递的）
  2. 简单的流程说明（如记录数据、提交作业的步骤）
  3. 阶段性总结

- **投入策略**：轻量化处理或省略。用图文、音频、或教师现场引导即可
- **替代方案**：图文步骤卡、清晰的任务卡、教师引导语脚本

### 视频素材的优质替代方案

| **替代方案** | **最佳适用场景** | **优点** | **注意事项** |
| :--- | :--- | :--- | :--- |
| 互动式模拟/微交互（H5等） | 解释动态原理、允许学生"试错"探究 | 参与感最强，能替代"演示型视频" | 开发成本可能高于视频 |
| 高质量信息图/动态图文 | 展示步骤、流程、结构、对比数据 | 信息密度高，一目了然。成本低 | 设计感至关重要 |
| 实物/道具"开箱"与演示 | 学具类课程 | 触觉学习，记忆深刻。创造"仪式感" | 需配套极清晰的图文指南 |
| 播客式音频故事/对话 | 讲述背景故事、创设情境 | 解放双眼，激发想象。成本低 | 对播音员声音表现力要求高 |
| 精心设计的"挑战任务卡" | 直接用"挑战书"或"密函"作为导入 | 零成本，高参与 | 文案和平面设计需非常出色 |

## 前瞻探索：构建"科创大陆"

### 核心构想

提出一种超越单点课程、以**统一世界观**（如"科创大陆"）贯穿所有学习体验的顶层设计思路。

- **产品**：所有课程与活动，都是探索这个宏大世界的一个个"副本"或"赛季"
- **学生**：是这个世界中的"探索者"或"创造者"，拥有持续成长的身份
- **学习**：是完成世界中的任务、解决世界性难题、推动文明进程的"探险"行为

### 潜在价值

1. **终极意义与动机**：为"为何要学"提供超越功利的、持久的情感与意义驱动
2. **跨学段/跨学科的自然融合**：世界的不同区域与纪元，可自然对应不同年龄段的认知与不同领域的知识
3. **学习成果的资产化与社交化**：学生在课程中的所有作品、数据、决策，都可转化为其在世界中的"资产"、"声望"或"贡献"
4. **产品形态的无限扩展**：新的科技、社会议题可作为"世界的新事件"无缝融入

### 对现有工作流的可能影响

若未来采纳此方向，它将作为**最顶层的战略叙事层**：

- **阶段一**：产出《世界观基础设定与编年史》
- **阶段二**：学期规划变为"赛季主题"与"大陆史诗篇章"规划
- **阶段三**：单元驱动问题将源于世界内的重大事件或危机
- **阶段四/五**：试点是"区域测试"，交付的不仅是课程，更是"世界入场券"
